# National Security Data Science Interview — Synthetic Research Lab

**Applied Statistics | Python | SQL | Analytics | Visualization | Decision Intelligence**

> **Status: functional MVP, not the full 26-section curriculum.** This public portfolio project uses entirely synthetic observations. It does not imply security clearance, government affiliation, operational deployment, or professional experience.

## What works today

- Reproducible synthetic observations with regional, temporal and source fields.
- Welch two-sample statistical test with a 95% confidence interval.
- Isolation Forest anomaly baseline, with no inference that anomalies are threats.
- DuckDB SQL exercises featuring CTEs and window functions.
- Streamlit dashboard with technical and executive views.
- Interactive interview CLI with self-assessment rubrics.
- Pytest tests and reusable Python package.

## Phase 2: practical Python and SQL labs

Implemented **12 Python coding challenges** and **12 executable SQL interview queries** with automated tests. See [phase 2 learning guide](docs/phase2_python_sql.md).

Run the SQL lab: `python scripts/run_sql_lab.py`.

## Setup — Windows PowerShell (Python 3.11+)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/generate_data.py --rows 1000
.\.venv\Scripts\python.exe scripts/run_analysis.py
.\.venv\Scripts\python.exe scripts/interview.py --topic statistics
.\.venv\Scripts\python.exe -m streamlit run app.py
```

For SQL, open DuckDB and execute `sql/01_analytics.sql` from the repository root after generating data.

## Methodological cautions

- Welch's t-test assumes independent observations; synthetic example only.
- Statistical significance is not evidence of operational importance or causality.
- Isolation Forest outliers are not evidence of malicious activity.
- The confidence interval concerns a difference of population means under model assumptions.
- All results must be generated by executing code; no claimed real-world validation.
